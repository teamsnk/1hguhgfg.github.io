POSTER MOTION STUDIO ULTRA
==========================

Ei folder-e ekta-i file ache: index.html. Kono install, server ba internet-e upload lage na (shudhu Bangla font-er jonno Google Fonts-e internet lage).

CLIENT KE DEWAR 2 TA UPAY
-------------------------
1) Live link diye (shobcheye shohoj)
   - https://app.netlify.com/drop e jan
   - ei folder ta (ba index.html) drag kore felun
   - 10 second e link pabe, oi link client ke pathan

2) File diye
   - index.html client ke pathan, double-click korle Chrome/Edge-e khulbe

CLIENT ER JONNO NIYOM
---------------------
- Chrome ba Edge e kholen (MP4 ar bhalo kaj-er jonno).
- Background ছবি upload korun, dan pashe lekha, ronge ar animation thik korun.
- Export video chapar por video-r shoman shomoy lage (10 sec video = ~10 sec). Tab khola ar samne rakhun.
- Audio nai, shudhu motion ar text.
- "More options" e style, length, size bodlano jay. Size ছবি dekhe auto set hoy.
